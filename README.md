# Холмогорское подворье — сайт фермерского рынка

Сайт-портфолио фермерского рынка в Калининградской области с интерактивной
3D-моделью: осмотр здания снаружи и прогулка по торговому залу от первого лица
с кликабельными зонами.

Собранная версия публикуется на GitHub Pages из ветки `gh-pages`.

## Запуск

```
npm install
npm run dev      # локальная разработка, http://localhost:5173
npm run build    # сборка в dist/
```

Сборка состоит из трёх шагов: `vite build`, затем `scripts/seo.mjs`
(Open Graph, JSON-LD, sitemap, robots) и `scripts/relativize.mjs`.

Последний нужен для GitHub Pages: по всему сайту ссылки заданы от корня
(`/catalog.html`, `/img/...`), а на Pages сайт лежит в подпапке, и такие
ссылки уводят на корень домена. Скрипт снимает ведущий слэш в собранных
страницах. Адрес для canonical и sitemap задаётся переменной `SITE_URL`.

## 3D-модель

| Файл | Что это |
|---|---|
| `public/models/market.glb` | экстерьер, фасады |
| `public/models/interior.glb` | торговый зал, редакция 26 |
| `src/islands.js` | зоны зала: номера, назначения, габариты, привязки |

`src/islands.js` **генерируемый** — правки вносить в
`scripts/model/zones_from_album.py`. Геометрия зон берётся из выдачи
проектировщика (`Market_Model_Data.json`), описания — из альбома компоновки.

Конвейер подготовки моделей и подводные камни описаны в
`scripts/model/README.md`. Отдельный самодостаточный просмотрщик модели
одним HTML-файлом собирается скриптами из `scripts/viewer/`.

## Структура

```
index.html, *.html      41 страница (MPA)
src/                    модули страниц, 3D-сцена, данные
public/models           модели, public/draco — декодер Draco
scripts/                сборочные шаги и подготовка моделей
```

Данные арендаторов, событий и товаров в `src/data*.js` — демонстрационные.
